## Methodology & honest caveats

- **Catalog = 9 products, one category (audio).** Recall@k is near-trivial at this size; **NDCG/MRR (ordering quality) are the meaningful signals.** Sanity check, not a benchmark.
- **Relevance labels are attribute-based** (brand, wired/wireless, neckband/TWS, bass-in-name) to avoid circularity. `attribute`-tier is objective; `semantic`-tier (bass/budget) is softer and documented per query in the golden set.
- Reranker: cross-encoder `BAAI/bge-reranker-base` (local, fastembed); logit -> sigmoid -> relevance feeding the ranking blend.

## Conclusion: reranker OFF by default

- The cross-encoder reranker improved MRR (0.8333 -> 0.8828) but **regressed NDCG@3** (0.8022 -> 0.7776) and **Recall@3** (0.8187 -> 0.7458), and did **not** lift the semantic/bass tier. Kept behind a flag (`rerank_enabled`, default False) per Decision 3 — measure, don't assume.

## CI regression gate (production default = hybrid-only)

- Gate: **NDCG@3 ≥ 0.8022 − 0.05** and **MRR ≥ 0.8333 − 0.05**.
- Re-baseline whenever retrieval, ranking weights, or the golden set change.
